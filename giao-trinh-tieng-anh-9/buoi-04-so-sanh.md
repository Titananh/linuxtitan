## 📚 PHẦN 2: LÝ THUYẾT - SO SÁNH HƠN (25 PHÚT)

### 2.1. ĐỊNH NGHĨA

**So sánh hơn (Comparative):** Dùng để so sánh 2 người/vật với nhau

### 2.2. THẦN CHÚ

```
┌─────────────────────────────────────────────────────┐
│  ⭐ "THAN LÀ HƠN" - Thấy THAN → So sánh HƠN         │
└─────────────────────────────────────────────────────┘
```

### 2.3. CẤU TRÚC

#### 📌 Tính từ ngắn (1 âm tiết hoặc 2 âm tiết tận cùng -y, -er, -ow, -le):

```
S1 + be + Adj-ER + THAN + S2
```

**Quy tắc thêm -ER:**

| Quy tắc | Ví dụ |
|---------|-------|
| Thông thường: + er | tall → taller, old → older |
| Tận cùng -e: + r | nice → nicer, large → larger |
| Tận cùng phụ âm + y: đổi y → ier | happy → happier, easy → easier |
| 1 nguyên âm + 1 phụ âm: gấp đôi + er | big → bigger, hot → hotter |

**Ví dụ:**
- Tom is **taller than** John.
- This book is **cheaper than** that one.
- My room is **bigger than** yours.

#### 📌 Tính từ dài (2 âm tiết trở lên):

```
S1 + be + MORE + Adj + THAN + S2
```

**Ví dụ:**
- English is **more interesting than** Math.
- This city is **more beautiful than** my hometown.
- Life in the city is **more expensive than** in the countryside.

### 2.4. BẢNG PHÂN LOẠI TÍNH TỪ

| Tính từ ngắn | Tính từ dài |
|--------------|-------------|
| tall, short, old, young | beautiful, interesting |
| big, small, fast, slow | expensive, comfortable |
| hot, cold, long, high | important, difficult |
| happy, easy, busy | convenient, crowded |
| clever, simple, narrow | modern, traditional |

## 📚 PHẦN 3: LÝ THUYẾT - SO SÁNH NHẤT (20 PHÚT)

### 3.1. ĐỊNH NGHĨA

**So sánh nhất (Superlative):** Dùng để so sánh 1 người/vật với tất cả những cái còn lại (≥ 3)

### 3.2. THẦN CHÚ

```
┌─────────────────────────────────────────────────────┐
│  ⭐ "THE LÀ NHẤT" - Thấy THE + adj → So sánh NHẤT   │
└─────────────────────────────────────────────────────┘
```

### 3.3. CẤU TRÚC

#### 📌 Tính từ ngắn:

```
S + be + THE + Adj-EST + (in/of...)
```

**Quy tắc thêm -EST:**

| Quy tắc | Ví dụ |
|---------|-------|
| Thông thường: + est | tall → tallest, old → oldest |
| Tận cùng -e: + st | nice → nicest, large → largest |
| Tận cùng phụ âm + y: đổi y → iest | happy → happiest, easy → easiest |
| 1 nguyên âm + 1 phụ âm: gấp đôi + est | big → biggest, hot → hottest |

**Ví dụ:**
- Tom is **the tallest** student in my class.
- This is **the cheapest** book in the store.
- Mount Everest is **the highest** mountain in the world.

#### 📌 Tính từ dài:

```
S + be + THE MOST + Adj + (in/of...)
```

**Ví dụ:**
- Ha Long Bay is **the most beautiful** place in Vietnam.
- This is **the most expensive** restaurant in town.
- She is **the most intelligent** student in our school.

### 3.4. DÙNG "IN" HAY "OF"?

| Dùng IN | Dùng OF |
|---------|---------|
| + Địa điểm, nhóm | + Số lượng, danh sách |
| in the world | of all |
| in my class | of the three |
| in this city | of my friends |
| in Vietnam | of these books |

## 📚 PHẦN 4: TÍNH TỪ BẤT QUY TẮC (15 PHÚT)

### 4.1. BẢNG TÍNH TỪ BẤT QUY TẮC (PHẢI THUỘC!)

```
┌─────────────────────────────────────────────────────────────┐
│  ⚠️ PHẦN NÀY HỌC SINH HAY SAI NHẤT - PHẢI HỌC KỸ!          │
└─────────────────────────────────────────────────────────────┘
```

| Tính từ | So sánh hơn | So sánh nhất | Nghĩa |
|---------|-------------|--------------|-------|
| **good** | better | the best | tốt |
| **bad** | worse | the worst | xấu, tệ |
| **far** | farther/further | the farthest/furthest | xa |
| **much/many** | more | the most | nhiều |
| **little** | less | the least | ít |
| **old** | older/elder | the oldest/eldest | già (elder: anh/chị) |

### 4.2. VÈ ĐỌC THUỘC

```
🎵 BÀI VÈ TÍNH TỪ BẤT QUY TẮC 🎵

"Good - Better - Best, nhớ chưa?
Bad - Worse - Worst, đừng nhầm nha!
Far - Farther - Farthest, xa xa xa,
Much/Many - More - Most, nhiều nhiều thật là nhiều!
Little - Less - Least, ít ít thôi!"
```

### 4.3. VÍ DỤ MINH HỌA

| Câu đúng | Câu sai |
|----------|---------|
| ✅ This book is **better than** that one. | ❌ This book is **gooder than** that one. |
| ✅ Today's weather is **worse than** yesterday's. | ❌ Today's weather is **badder than** yesterday's. |
| ✅ He is **the best** student in class. | ❌ He is **the goodest** student in class. |
| ✅ This is **the worst** movie I've ever seen. | ❌ This is **the baddest** movie I've ever seen. |
