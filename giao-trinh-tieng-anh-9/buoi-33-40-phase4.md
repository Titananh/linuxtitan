## 📚 TÓM TẮT CÁC "THẦN CHÚ"

### 1. Giới từ
```
"PHỄU ĐỔ TỪ TRÊN XUỐNG:
IN cho tháng, mùa, năm,
ON cho ngày và thứ,
AT cho giờ cụ thể!"
```

### 2. There is/are
```
"Nhìn danh từ ĐẦU TIÊN:
Đầu ít thì IS, đầu nhiều thì ARE"
```

### 3. Câu gián tiếp
```
"LÙI THÌ - ĐỔI NGÔI - ĐỔI TRẠNG TỪ"
```

### 4. So sánh
```
"THAN là HƠN, THE là NHẤT"
```

### 5. Wish
```
"ƯỚC LÀ PHẢI LÙI - Dùng WERE cho mọi ngôi"
```

### 6. Used to
```
"USED TO = ĐÃ TỪNG (giờ không làm nữa)"
```

### 7. Bị động
```
"O ĐẢO LÊN - BE + V3 - BY S"
```

### 8. Tính từ bất quy tắc
```
"Good - Better - Best
Bad - Worse - Worst
Far - Farther - Farthest"
```
