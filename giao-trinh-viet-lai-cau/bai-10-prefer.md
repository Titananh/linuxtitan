## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ PREFER / WOULD RATHER

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  "PREFER + V-ING/N + TO + V-ING/N" (Thích A hơn B)          │
│  "WOULD RATHER + V + THAN + V" (Thích A hơn B - nguyên thể) │
│                                                             │
│  📌 PREFER: dùng TO (to + V-ing/N)                          │
│  📌 WOULD RATHER: dùng THAN (than + V nguyên thể)           │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. CẤU TRÚC PREFER

**Công thức 1: PREFER + V-ING + TO + V-ING**
```
S + PREFER(S) + V-ING + TO + V-ING
```

**Ví dụ:**
```
✓ I prefer reading to watching TV.
  (Tôi thích đọc sách hơn xem TV)

✓ She prefers swimming to running.
  (Cô ấy thích bơi hơn chạy bộ)
```

**Công thức 2: PREFER + N + TO + N**
```
S + PREFER(S) + N + TO + N
```

**Ví dụ:**
```
✓ I prefer tea to coffee.
  (Tôi thích trà hơn cà phê)

✓ He prefers football to basketball.
  (Anh ấy thích bóng đá hơn bóng rổ)
```

**Công thức 3: PREFER + TO V + RATHER THAN + V**
```
S + PREFER(S) + TO + V + RATHER THAN + V (nguyên thể)
```

**Ví dụ:**
```
✓ I prefer to stay home rather than go out.
  (Tôi thích ở nhà hơn là ra ngoài)

✓ She prefers to cook rather than eat out.
  (Cô ấy thích nấu ăn hơn là ăn ngoài)
```

### 1.3. CẤU TRÚC WOULD RATHER

**Công thức 1: WOULD RATHER + V + THAN + V** (Cùng chủ ngữ)
```
S + WOULD RATHER + V (nguyên thể) + THAN + V (nguyên thể)
```

**Ví dụ:**
```
✓ I would rather stay home than go out.
  (Tôi thà ở nhà còn hơn ra ngoài)

✓ She would rather read than watch TV.
  (Cô ấy thà đọc sách còn hơn xem TV)
```

**Công thức 2: WOULD RATHER + S + V (QKĐ)** (Khác chủ ngữ)
```
S1 + WOULD RATHER + S2 + V-ED/V2 (QKĐ)
```

**Ví dụ:**
```
✓ I would rather you stayed here.
  (Tôi muốn bạn ở đây hơn)

✓ She would rather he didn't smoke.
  (Cô ấy muốn anh ấy không hút thuốc)
```

**Công thức 3: WOULD RATHER NOT + V** (Phủ định)
```
S + WOULD RATHER NOT + V (nguyên thể)
```

**Ví dụ:**
```
✓ I would rather not go out tonight.
  (Tôi thà không ra ngoài tối nay)
```

### 1.4. WOULD PREFER

**Công thức:**
```
S + WOULD PREFER + TO V + RATHER THAN + V
S + WOULD PREFER + N + TO + N
```

**Ví dụ:**
```
✓ I would prefer to stay home rather than go out.
✓ I would prefer tea to coffee.
```

## 🔄 PHẦN 2: CHUYỂN ĐỔI CÂU

### 2.1. PREFER ↔ WOULD RATHER

```
┌─────────────────────────────────────────────────────────────┐
│  📌 QUY TẮC CHUYỂN ĐỔI:                                     │
│                                                             │
│  PREFER + V-ING + TO + V-ING                                │
│  = WOULD RATHER + V + THAN + V                              │
│                                                             │
│  ⚠️ LƯU Ý:                                                  │
│  - Đổi V-ING → V nguyên thể                                 │
│  - Đổi TO → THAN                                            │
└─────────────────────────────────────────────────────────────┘
```

**Ví dụ:**
```
I prefer staying home to going out.
= I would rather stay home than go out.

She prefers reading to watching TV.
= She would rather read than watch TV.

He prefers tea to coffee.
= He would rather have/drink tea than coffee.
```

### 2.2. LIKE...BETTER ↔ PREFER ↔ WOULD RATHER

```
S + LIKE + N/V-ING + BETTER THAN + N/V-ING
= S + PREFER + N/V-ING + TO + N/V-ING
= S + WOULD RATHER + V + THAN + V
```

**Ví dụ:**
```
I like tea better than coffee.
= I prefer tea to coffee.
= I would rather drink tea than coffee.
```

## 📊 PHẦN 3: BẢNG TÓM TẮT

| Cấu trúc | Công thức | Ví dụ |
|----------|-----------|-------|
| **PREFER + V-ing** | S + prefer + V-ing + to + V-ing | I prefer reading to watching TV. |
| **PREFER + N** | S + prefer + N + to + N | I prefer tea to coffee. |
| **PREFER + to V** | S + prefer + to V + rather than + V | I prefer to stay rather than go. |
| **WOULD RATHER** | S + would rather + V + than + V | I'd rather stay than go. |
| **WOULD RATHER (khác S)** | S1 + would rather + S2 + V2 | I'd rather you stayed. |
