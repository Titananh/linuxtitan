## 📚 PHẦN 1: ĐỊNH LƯỢNG TỪ CƠ BẢN (30 PHÚT)

### 1.1. PHÂN LOẠI DANH TỪ

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ: "ĐẾM ĐƯỢC CÓ S, KHÔNG ĐẾM ĐƯỢC KHÔNG S"       │
└─────────────────────────────────────────────────────────────┘
```

| Danh từ đếm được (Countable) | Danh từ không đếm được (Uncountable) |
|------------------------------|--------------------------------------|
| Có thể đếm 1, 2, 3... | Không đếm được |
| Có số ít và số nhiều | Chỉ có 1 dạng |
| a book, books | water, rice, money |
| an apple, apples | milk, bread, information |

### 1.2. BẢNG ĐỊNH LƯỢNG TỪ

| Định lượng từ | Đếm được | Không đếm được | Loại câu |
|---------------|----------|----------------|----------|
| **a / an** | ✓ (số ít) | ✗ | Khẳng định |
| **some** | ✓ (số nhiều) | ✓ | Khẳng định |
| **any** | ✓ (số nhiều) | ✓ | Phủ định, Nghi vấn |
| **much** | ✗ | ✓ | Phủ định, Nghi vấn |
| **many** | ✓ (số nhiều) | ✗ | Cả 3 loại |
| **a lot of / lots of** | ✓ | ✓ | Khẳng định |
| **a few** | ✓ | ✗ | Khẳng định |
| **a little** | ✗ | ✓ | Khẳng định |
| **few** | ✓ | ✗ | Cả 3 loại |
| **little** | ✗ | ✓ | Cả 3 loại |

### 1.3. CHI TIẾT TỪNG ĐỊNH LƯỢNG TỪ

#### 📌 A / AN:
```
A + danh từ bắt đầu bằng phụ âm: a book, a car
AN + danh từ bắt đầu bằng nguyên âm (a, e, i, o, u): an apple, an egg
```

#### 📌 SOME / ANY:

| SOME | ANY |
|------|-----|
| Câu khẳng định | Câu phủ định, nghi vấn |
| There is **some** milk. | There isn't **any** milk. |
| I have **some** books. | Do you have **any** books? |

**Ngoại lệ:** Dùng SOME trong câu hỏi khi:
- Mời: Would you like **some** coffee?
- Yêu cầu: Can I have **some** water?

#### 📌 MUCH / MANY:

| MANY | MUCH |
|------|------|
| + Danh từ đếm được (số nhiều) | + Danh từ không đếm được |
| How **many** books do you have? | How **much** money do you have? |
| I don't have **many** friends. | I don't have **much** time. |

#### 📌 A LOT OF / LOTS OF:
```
Dùng cho CẢ HAI loại danh từ trong câu KHẲNG ĐỊNH
```
- I have **a lot of** books. (đếm được)
- I have **a lot of** money. (không đếm được)

## 📚 PHẦN 2: FEW / LITTLE, A FEW / A LITTLE (25 PHÚT)

### 2.1. PHÂN BIỆT NGHĨA

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ "A" = CÓ MỘT ÍT (đủ dùng)                               │
│  KHÔNG CÓ "A" = RẤT ÍT (gần như không có)                  │
└─────────────────────────────────────────────────────────────┘
```

| | Đếm được (Countable) | Không đếm được (Uncountable) |
|---|----------------------|------------------------------|
| **Có một ít** (tích cực) | **a few** + N số nhiều | **a little** + N |
| **Rất ít** (tiêu cực) | **few** + N số nhiều | **little** + N |

### 2.2. VÍ DỤ SO SÁNH

**A FEW vs FEW:**
```
I have a few friends. (Tôi có vài người bạn - đủ)
I have few friends. (Tôi có rất ít bạn - không đủ, buồn)
```

**A LITTLE vs LITTLE:**
```
There is a little milk in the fridge. (Còn một ít sữa - đủ dùng)
There is little milk in the fridge. (Còn rất ít sữa - gần hết)
```

### 2.3. BÀI TẬP NHANH

```
1. I have ___ money. I can buy lunch. (a little / little)
2. She has ___ friends. She is very lonely. (a few / few)
3. There is ___ sugar left. We need to buy more. (a little / little)
4. I need ___ minutes to finish. (a few / few)
5. He speaks ___ English. He can't communicate well. (a little / little)
```

**Đáp án:** 1. a little, 2. few, 3. little, 4. a few, 5. little
