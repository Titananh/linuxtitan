## 🎯 MỤC TIÊU BÀI HỌC

Sau bài học này, học sinh có thể:
1. ✅ Phân biệt câu điều kiện loại 0, 1, 2, 3
2. ✅ Viết lại câu điều kiện từ câu thường
3. ✅ Chuyển đổi giữa các loại câu điều kiện
4. ✅ Làm đúng ≥ 80% bài tập

## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ CÂU ĐIỀU KIỆN

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  LOẠI 0: "SỰ THẬT" → IF + HTĐ, HTĐ                          │
│  LOẠI 1: "CÓ THỂ" → IF + HTĐ, WILL + V                      │
│  LOẠI 2: "KHÔNG CÓ THẬT Ở HT" → IF + QKĐ, WOULD + V        │
│  LOẠI 3: "KHÔNG CÓ THẬT Ở QK" → IF + QKHT, WOULD HAVE V3   │
│                                                             │
│  📌 NHỚ: "IF LÙI 1 THÌ, MỆNH ĐỀ CHÍNH THÊM WOULD"          │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. CÂU ĐIỀU KIỆN LOẠI 0 (ZERO CONDITIONAL)

**Công thức:**
```
IF + S + V (HTĐ), S + V (HTĐ)
```

**Cách dùng:** Diễn tả **sự thật hiển nhiên**, quy luật tự nhiên

**Ví dụ:**
```
✓ If you heat water to 100°C, it boils.
  (Nếu bạn đun nước đến 100°C, nó sôi)

✓ If it rains, the ground gets wet.
  (Nếu trời mưa, mặt đất ướt)

✓ If you don't eat, you get hungry.
  (Nếu bạn không ăn, bạn đói)
```

### 1.3. CÂU ĐIỀU KIỆN LOẠI 1 (FIRST CONDITIONAL)

**Công thức:**
```
IF + S + V (HTĐ), S + WILL/CAN/MAY + V
```

**Cách dùng:** Diễn tả điều kiện **có thể xảy ra** ở tương lai

**Ví dụ:**
```
✓ If it rains tomorrow, I will stay home.
  (Nếu ngày mai trời mưa, tôi sẽ ở nhà)

✓ If you study hard, you will pass the exam.
  (Nếu bạn học chăm, bạn sẽ đậu kỳ thi)

✓ If she comes early, we can go to the cinema.
  (Nếu cô ấy đến sớm, chúng tôi có thể đi xem phim)
```

### 1.4. CÂU ĐIỀU KIỆN LOẠI 2 (SECOND CONDITIONAL)

**Công thức:**
```
IF + S + V-ED/V2 (QKĐ), S + WOULD/COULD/MIGHT + V
```

**Cách dùng:** Diễn tả điều kiện **không có thật ở hiện tại**, giả định

**Lưu ý:** Với động từ "to be", dùng "were" cho tất cả các ngôi

**Ví dụ:**
```
✓ If I were rich, I would buy a big house.
  (Nếu tôi giàu, tôi sẽ mua một ngôi nhà lớn) - Nhưng tôi không giàu

✓ If she had a car, she would drive to work.
  (Nếu cô ấy có xe hơi, cô ấy sẽ lái xe đi làm) - Nhưng cô ấy không có xe

✓ If I were you, I would study harder.
  (Nếu tôi là bạn, tôi sẽ học chăm hơn) - Dùng để khuyên
```

### 1.5. CÂU ĐIỀU KIỆN LOẠI 3 (THIRD CONDITIONAL)

**Công thức:**
```
IF + S + HAD + V3 (QKHT), S + WOULD/COULD/MIGHT + HAVE + V3
```

**Cách dùng:** Diễn tả điều kiện **không có thật ở quá khứ**, tiếc nuối

**Ví dụ:**
```
✓ If I had studied harder, I would have passed the exam.
  (Nếu tôi đã học chăm hơn, tôi đã đậu kỳ thi) - Nhưng tôi không học chăm

✓ If she had left earlier, she wouldn't have missed the train.
  (Nếu cô ấy đi sớm hơn, cô ấy đã không lỡ tàu) - Nhưng cô ấy đi trễ

✓ If it hadn't rained, we would have gone out.
  (Nếu trời không mưa, chúng tôi đã ra ngoài) - Nhưng trời đã mưa
```

## 📊 PHẦN 2: BẢNG TÓM TẮT

| Loại | Mệnh đề IF | Mệnh đề chính | Cách dùng |
|------|------------|---------------|-----------|
| **0** | IF + HTĐ | HTĐ | Sự thật hiển nhiên |
| **1** | IF + HTĐ | WILL + V | Có thể xảy ra (tương lai) |
| **2** | IF + QKĐ | WOULD + V | Không có thật (hiện tại) |
| **3** | IF + QKHT | WOULD HAVE + V3 | Không có thật (quá khứ) |

## 🔄 PHẦN 3: VIẾT LẠI CÂU ĐIỀU KIỆN

### 3.1. TỪ CÂU THƯỜNG → CÂU ĐIỀU KIỆN LOẠI 2

```
┌─────────────────────────────────────────────────────────────┐
│  📌 QUY TẮC:                                                │
│                                                             │
│  Câu thường (không có thật ở HT) → IF loại 2                │
│                                                             │
│  ① ĐỔI KHẲNG ĐỊNH → PHỦ ĐỊNH (hoặc ngược lại)               │
│  ② DÙNG: IF + QKĐ, WOULD + V                                │
└─────────────────────────────────────────────────────────────┘
```

**Ví dụ:**
```
He doesn't have money, so he can't buy a car.
→ If he had money, he could/would buy a car.

She is sick, so she stays home.
→ If she weren't sick, she wouldn't stay home.

I don't know her address, so I can't visit her.
→ If I knew her address, I could visit her.
```

### 3.2. TỪ CÂU THƯỜNG → CÂU ĐIỀU KIỆN LOẠI 3

```
┌─────────────────────────────────────────────────────────────┐
│  📌 QUY TẮC:                                                │
│                                                             │
│  Câu thường (không có thật ở QK) → IF loại 3                │
│                                                             │
│  ① ĐỔI KHẲNG ĐỊNH → PHỦ ĐỊNH (hoặc ngược lại)               │
│  ② DÙNG: IF + HAD V3, WOULD HAVE V3                         │
└─────────────────────────────────────────────────────────────┘
```

**Ví dụ:**
```
He didn't study hard, so he failed the exam.
→ If he had studied hard, he would have passed the exam.

She was late, so she missed the bus.
→ If she hadn't been late, she wouldn't have missed the bus.

I didn't have an umbrella, so I got wet.
→ If I had had an umbrella, I wouldn't have got wet.
```

### 3.3. UNLESS = IF...NOT

**Công thức:**
```
IF + S + NOT + V = UNLESS + S + V (khẳng định)
```

**Ví dụ:**
```
If you don't hurry, you will be late.
= Unless you hurry, you will be late.

If she doesn't study, she won't pass.
= Unless she studies, she won't pass.
```

### 3.4. WITHOUT = IF...NOT

**Công thức:**
```
WITHOUT + N = IF + S + NOT + V
```

**Ví dụ:**
```
Without water, we can't survive.
= If we didn't have water, we couldn't survive.

Without his help, I would have failed.
= If he hadn't helped me, I would have failed.
```
