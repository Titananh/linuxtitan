## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ IT TAKES / SPEND

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  "IT TAKES + NGƯỜI + THỜI GIAN + TO V"                      │
│  (Mất bao lâu để ai đó làm gì)                              │
│                                                             │
│  "NGƯỜI + SPEND + THỜI GIAN + V-ING"                        │
│  (Ai đó dành bao lâu để làm gì)                             │
│                                                             │
│  📌 IT TAKES: TO + V (nguyên thể)                           │
│  📌 SPEND: V-ING (động từ thêm -ing)                        │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. CẤU TRÚC IT TAKES

**Công thức:**
```
IT + TAKES/TOOK + O (người) + TIME + TO + V (nguyên thể)
```

**Ví dụ:**
```
✓ It takes me 30 minutes to get to school.
  (Tôi mất 30 phút để đến trường)

✓ It took her 2 hours to finish the homework.
  (Cô ấy mất 2 tiếng để hoàn thành bài tập)

✓ It will take us 3 days to complete the project.
  (Chúng tôi sẽ mất 3 ngày để hoàn thành dự án)
```

### 1.3. CẤU TRÚC SPEND

**Công thức:**
```
S + SPEND(S)/SPENT + TIME + V-ING
S + SPEND(S)/SPENT + TIME + ON + N (danh từ)
```

**Ví dụ:**
```
✓ I spend 30 minutes walking to school.
  (Tôi dành 30 phút đi bộ đến trường)

✓ She spent 2 hours finishing the homework.
  (Cô ấy dành 2 tiếng hoàn thành bài tập)

✓ He spends a lot of time on his studies.
  (Anh ấy dành nhiều thời gian cho việc học)
```

## 🔄 PHẦN 2: CHUYỂN ĐỔI CÂU

### 2.1. IT TAKES ↔ SPEND

```
┌─────────────────────────────────────────────────────────────┐
│  📌 QUY TẮC CHUYỂN ĐỔI:                                     │
│                                                             │
│  IT TAKES + O + TIME + TO V                                 │
│  = S + SPEND + TIME + V-ING                                 │
│                                                             │
│  ⚠️ LƯU Ý:                                                  │
│  - Đổi "TO V" → "V-ING"                                     │
│  - Đổi tân ngữ (O) → chủ ngữ (S)                            │
└─────────────────────────────────────────────────────────────┘
```

**Ví dụ:**
```
It takes me 20 minutes to walk to school.
= I spend 20 minutes walking to school.

It took her 3 hours to do her homework.
= She spent 3 hours doing her homework.

It will take us 2 days to paint the house.
= We will spend 2 days painting the house.
```

### 2.2. CÁC BIẾN THỂ KHÁC

**HOW LONG:**
```
How long does it take you to get to school?
= How long do you spend getting to school?
```

**COST (tiền bạc):**
```
It costs me $100 to repair the car.
= I spend $100 on repairing the car. / I spend $100 (on) the car repair.
```

## 📊 PHẦN 3: BẢNG TÓM TẮT

| Cấu trúc | Công thức | Ví dụ |
|----------|-----------|-------|
| **IT TAKES** | It takes + O + time + to V | It takes me 1 hour to cook. |
| **SPEND (V-ing)** | S + spend + time + V-ing | I spend 1 hour cooking. |
| **SPEND (on + N)** | S + spend + time + on + N | I spend 1 hour on cooking. |
