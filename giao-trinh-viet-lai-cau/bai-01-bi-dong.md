# 📝 BÀI 1: CÂU BỊ ĐỘNG (PASSIVE VOICE)

## 📋 THÔNG TIN BÀI HỌC
| Mục | Chi tiết |
|-----|----------|
| **Thời lượng:** | 90 phút |
| **Độ khó:** | ⭐⭐⭐ Trung bình |
| **Tần suất thi:** | ⭐⭐⭐⭐⭐ RẤT CAO |
| **Điểm trong đề:** | 0.5 - 1 điểm |

---

## 🎯 MỤC TIÊU BÀI HỌC

Sau bài học này, học sinh có thể:
1. ✅ Hiểu được khi nào dùng câu bị động
2. ✅ Thuộc công thức bị động các thì
3. ✅ Chuyển đổi câu chủ động sang bị động chính xác
4. ✅ Làm đúng ≥ 80% bài tập viết lại câu bị động

## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. ĐỊNH NGHĨA

| Loại câu | Đặc điểm | Ví dụ |
|----------|----------|-------|
| **Chủ động (Active)** | Chủ ngữ **thực hiện** hành động | The dog **bites** the cat. |
| **Bị động (Passive)** | Chủ ngữ **chịu** tác động | The cat **is bitten** by the dog. |

### 1.2. KHI NÀO DÙNG CÂU BỊ ĐỘNG?

```
1. Khi KHÔNG BIẾT ai thực hiện hành động
   → My bike was stolen. (Ai lấy? Không biết)

2. Khi KHÔNG QUAN TRỌNG ai thực hiện  
   → The letter was sent yesterday. (Quan trọng là thư đã gửi)

3. Khi muốn NHẤN MẠNH đối tượng chịu tác động
   → Ha Long Bay was recognized as a World Heritage Site.
```

### 1.3. THẦN CHÚ BỊ ĐỘNG

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ: "O ĐẢO LÊN - BE + V3 - BY S"                  │
│                                                             │
│  ① Lấy TÂN NGỮ (O) làm chủ ngữ mới                         │
│  ② Động từ → BE + V3 (quá khứ phân từ)                     │
│  ③ CHỦ NGỮ cũ (S) → BY + tân ngữ (nếu cần)                 │
└─────────────────────────────────────────────────────────────┘
```

### 1.4. SƠ ĐỒ CHUYỂN ĐỔI

```
Chủ động:  Tom        eats      an apple.
           (S)        (V)       (O)
               ↓         ↓         ↓
Bị động:   An apple   is eaten   by Tom.
           (S mới)    (BE+V3)    (BY + tác nhân)
```

## 📊 PHẦN 2: BẢNG CÔNG THỨC BỊ ĐỘNG CÁC THÌ

### 2.1. BẢNG CÔNG THỨC ĐẦY ĐỦ

| Thì | Chủ động | Bị động |
|-----|----------|---------|
| **Hiện tại đơn** | S + V/V-s + O | S + **am/is/are** + V3 |
| **Hiện tại tiếp diễn** | S + am/is/are + V-ing + O | S + **am/is/are + being** + V3 |
| **Hiện tại hoàn thành** | S + have/has + V3 + O | S + **have/has been** + V3 |
| **Quá khứ đơn** | S + V-ed/V2 + O | S + **was/were** + V3 |
| **Quá khứ tiếp diễn** | S + was/were + V-ing + O | S + **was/were + being** + V3 |
| **Quá khứ hoàn thành** | S + had + V3 + O | S + **had been** + V3 |
| **Tương lai đơn** | S + will + V + O | S + **will be** + V3 |
| **Tương lai hoàn thành** | S + will have + V3 + O | S + **will have been** + V3 |
| **Modal verbs** | S + can/must/should + V + O | S + **can/must/should be** + V3 |

### 2.2. VÍ DỤ TỪNG THÌ

**① Hiện tại đơn:**
```
Active:  She cleans the room every day.
Passive: The room is cleaned (by her) every day.
```

**② Hiện tại tiếp diễn:**
```
Active:  They are building a new school.
Passive: A new school is being built (by them).
```

**③ Hiện tại hoàn thành:**
```
Active:  Someone has stolen my bike.
Passive: My bike has been stolen.
```

**④ Quá khứ đơn:**
```
Active:  Edison invented the light bulb.
Passive: The light bulb was invented by Edison.
```

**⑤ Quá khứ tiếp diễn:**
```
Active:  They were repairing the road.
Passive: The road was being repaired (by them).
```

**⑥ Quá khứ hoàn thành:**
```
Active:  Someone had cleaned the room before I arrived.
Passive: The room had been cleaned before I arrived.
```

**⑦ Tương lai đơn:**
```
Active:  They will finish the project tomorrow.
Passive: The project will be finished (by them) tomorrow.
```

**⑧ Modal verbs:**
```
Active:  You must do this exercise.
Passive: This exercise must be done (by you).
```

## 🔴 PHẦN 3: LƯU Ý QUAN TRỌNG

### 3.1. KHÔNG THỂ CHUYỂN SANG BỊ ĐỘNG KHI:

```
❌ Không có tân ngữ:
   - He sleeps. → KHÔNG THỂ chuyển
   - She arrived late. → KHÔNG THỂ chuyển

❌ Động từ nội động từ (intransitive verbs):
   - happen, occur, exist, appear, seem...
```

### 3.2. KHI NÀO LƯỢC BỎ "BY + TÁC NHÂN":

```
✅ Lược bỏ khi tác nhân là:
   - they, people, someone, somebody
   - Không quan trọng hoặc không biết

❌ Giữ lại khi tác nhân là:
   - Người/vật cụ thể, quan trọng
   - Cần nhấn mạnh ai thực hiện
```

### 3.3. BẢNG ĐỘNG TỪ BẤT QUY TẮC THƯỜNG GẶP

| V1 | V2 | V3 | Nghĩa |
|----|----|----|-------|
| do | did | **done** | làm |
| make | made | **made** | tạo |
| write | wrote | **written** | viết |
| build | built | **built** | xây |
| give | gave | **given** | cho |
| take | took | **taken** | lấy |
| see | saw | **seen** | thấy |
| send | sent | **sent** | gửi |
| speak | spoke | **spoken** | nói |
| steal | stole | **stolen** | ăn cắp |
| break | broke | **broken** | vỡ |
| choose | chose | **chosen** | chọn |
| eat | ate | **eaten** | ăn |
| find | found | **found** | tìm thấy |
| hold | held | **held** | cầm |
