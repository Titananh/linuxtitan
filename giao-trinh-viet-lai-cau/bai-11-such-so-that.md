## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ SO/SUCH...THAT

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  "SO + ADJ/ADV + THAT" → Quá...đến nỗi (không có danh từ)   │
│  "SUCH + (A/AN) + ADJ + N + THAT" → Quá...đến nỗi (có DT)  │
│                                                             │
│  📌 SO: đi với TÍNH TỪ / TRẠNG TỪ (không có danh từ)       │
│  📌 SUCH: đi với CỤM DANH TỪ (có danh từ)                   │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. CẤU TRÚC SO...THAT

**Công thức:**
```
S + V + SO + ADJ/ADV + THAT + S + V
```

**Ví dụ:**
```
✓ She is so beautiful that everyone admires her.
  (Cô ấy đẹp đến nỗi mọi người đều ngưỡng mộ cô ấy)

✓ He runs so fast that no one can catch him.
  (Anh ấy chạy nhanh đến nỗi không ai bắt kịp anh ấy)

✓ The weather was so cold that we stayed home.
  (Thời tiết lạnh đến nỗi chúng tôi ở nhà)
```

### 1.3. CẤU TRÚC SUCH...THAT

**Công thức 1: SUCH + A/AN + ADJ + N (số ít đếm được)**
```
S + V + SUCH + A/AN + ADJ + N + THAT + S + V
```

**Ví dụ:**
```
✓ She is such a beautiful girl that everyone admires her.
  (Cô ấy là một cô gái đẹp đến nỗi mọi người đều ngưỡng mộ)

✓ It was such a cold day that we stayed home.
  (Đó là một ngày lạnh đến nỗi chúng tôi ở nhà)
```

**Công thức 2: SUCH + ADJ + N (số nhiều / không đếm được)**
```
S + V + SUCH + ADJ + N (số nhiều/không đếm được) + THAT + S + V
```

**Ví dụ:**
```
✓ They are such kind people that everyone likes them.
  (Họ là những người tốt bụng đến nỗi mọi người đều thích họ)

✓ It was such beautiful weather that we went out.
  (Thời tiết đẹp đến nỗi chúng tôi ra ngoài)
```

### 1.4. TRƯỜNG HỢP ĐẶC BIỆT: SO + MANY/MUCH/FEW/LITTLE

```
┌─────────────────────────────────────────────────────────────┐
│  📌 DÙNG SO (không phải SUCH) với:                          │
│                                                             │
│  SO + MANY + N (đếm được, số nhiều)                         │
│  SO + MUCH + N (không đếm được)                             │
│  SO + FEW + N (đếm được, số nhiều)                          │
│  SO + LITTLE + N (không đếm được)                           │
└─────────────────────────────────────────────────────────────┘
```

**Ví dụ:**
```
✓ He has so many books that he can't read them all.
  (Anh ấy có nhiều sách đến nỗi không thể đọc hết)

✓ She has so much money that she doesn't know what to do.
  (Cô ấy có nhiều tiền đến nỗi không biết làm gì)

✓ There are so few students that the class was cancelled.
  (Có ít học sinh đến nỗi lớp bị hủy)
```

## 🔄 PHẦN 2: CHUYỂN ĐỔI CÂU

### 2.1. SO...THAT ↔ SUCH...THAT

```
┌─────────────────────────────────────────────────────────────┐
│  📌 QUY TẮC CHUYỂN ĐỔI:                                     │
│                                                             │
│  SO + ADJ + A/AN + N + THAT                                 │
│  = SUCH + A/AN + ADJ + N + THAT                             │
│                                                             │
│  ⚠️ LƯU Ý: Vị trí của A/AN thay đổi!                       │
│  SO: ADJ + A/AN + N                                         │
│  SUCH: A/AN + ADJ + N                                       │
└─────────────────────────────────────────────────────────────┘
```

**Ví dụ:**
```
She is so beautiful a girl that everyone admires her.
= She is such a beautiful girl that everyone admires her.

It was so cold a day that we stayed home.
= It was such a cold day that we stayed home.
```

### 2.2. SO/SUCH...THAT ↔ TOO...TO

```
S + V + SO + ADJ + THAT + S + CAN'T + V
= S + V + TOO + ADJ + (FOR O) + TO + V
```

**Ví dụ:**
```
The box is so heavy that I can't carry it.
= The box is too heavy (for me) to carry.

The coffee is so hot that she can't drink it.
= The coffee is too hot (for her) to drink.
```

### 2.3. SO/SUCH...THAT ↔ ENOUGH...TO

```
S + V + SO + ADJ + THAT + S + CAN + V
= S + V + ADJ + ENOUGH + (FOR O) + TO + V
```

**Ví dụ:**
```
She is so intelligent that she can solve the problem.
= She is intelligent enough to solve the problem.

He is so old that he can drive.
= He is old enough to drive.
```

## 📊 PHẦN 3: BẢNG TÓM TẮT

| Cấu trúc | Theo sau | Ví dụ |
|----------|----------|-------|
| **SO...THAT** | ADJ/ADV (không có N) | She is so beautiful that... |
| **SUCH...THAT** | (A/AN) + ADJ + N | She is such a beautiful girl that... |
| **SO + many/much** | + N | He has so many books that... |
| **SO + few/little** | + N | There is so little time that... |

