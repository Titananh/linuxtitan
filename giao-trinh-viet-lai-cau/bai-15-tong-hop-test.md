## 📚 PHẦN 1: BẢNG TÓM TẮT 14 CẤU TRÚC

### 1.1. BẢNG THẦN CHÚ TỔNG HỢP

```
┌─────────────────────────────────────────────────────────────────────┐
│  📌 15 THẦN CHÚ VIẾT LẠI CÂU - HỌC THUỘC LÒNG!                     │
├─────────────────────────────────────────────────────────────────────┤
│  1. BỊ ĐỘNG: "O đảo lên - BE V3 - BY S"                            │
│  2. SO SÁNH HƠN: "Than là Hơn" → S + V + more/adj-er + than        │
│  3. SO SÁNH NHẤT: "The là Nhất" → S + V + the most/adj-est         │
│  4. TOO: "Too = Quá...không thể" → too + adj + to V                │
│  5. ENOUGH: "Enough = Đủ để" → adj + enough + to V                 │
│  6. BECAUSE → BECAUSE OF: Mệnh đề → Cụm danh từ                    │
│  7. ALTHOUGH → DESPITE: Mệnh đề → Cụm danh từ/Ving                 │
│  8. IF 0: If + HTĐ, HTĐ (sự thật hiển nhiên)                       │
│  9. IF 1: If + HTĐ, will + V (có thể xảy ra)                       │
│  10. IF 2: If + QKĐ, would + V (không có thật ở hiện tại)          │
│  11. IF 3: If + QKHT, would have V3 (không có thật ở quá khứ)      │
│  12. WISH: "Ước là PHẢI LÙI" → Wish + QKĐ (trái ngược HT)          │
│  13. GIÁN TIẾP: "LÙI thì - ĐỔI ngôi - ĐỔI trạng từ"               │
│  14. IT TAKES: It takes + O + time + to V                          │
│  15. SPEND: S + spend + time + V-ing                               │
│  16. PREFER: S + prefer + V-ing + to + V-ing                       │
│  17. WOULD RATHER: S + would rather + V + than + V                 │
│  18. SUGGEST: S + suggest + V-ing / (that) S + (should) + V        │
│  19. SO...THAT: S + V + so + adj + that + S + V                    │
│  20. SUCH...THAT: S + V + such + (a/an) + adj + N + that + S + V   │
│  21. USED TO: S + used to + V (thói quen quá khứ)                  │
│  22. BE USED TO: S + be used to + V-ing (quen với)                 │
│  23. MĐQH rút gọn: CHỦ ĐỘNG → V-ing, BỊ ĐỘNG → V3                  │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.2. BẢNG CÔNG THỨC NHANH

| STT | Cấu trúc | Công thức | Ví dụ |
|-----|----------|-----------|-------|
| 1 | Bị động | S + BE + V3 | English is spoken. |
| 2 | So sánh hơn | ADJ-er/more ADJ + than | taller than |
| 3 | So sánh nhất | the + ADJ-est/most ADJ | the tallest |
| 4 | Too | too + ADJ + to V | too hot to drink |
| 5 | Enough | ADJ + enough + to V | old enough to drive |
| 6 | Because of | because of + N/Ving | because of the rain |
| 7 | Despite | despite + N/Ving | despite the rain |
| 8 | If 2 | If + V2, would + V | If I were... |
| 9 | Wish (HT) | wish + V2/were | I wish I were... |
| 10 | Wish (QK) | wish + had V3 | I wish I had studied |
| 11 | Gián tiếp | said + (that) + lùi thì | He said he was... |
| 12 | It takes | It takes + O + time + to V | It takes me 1 hour |
| 13 | Spend | S + spend + time + Ving | I spend 1 hour reading |
| 14 | Suggest | suggest + Ving | suggest going |

## 📊 PHẦN 3: ĐÁNH GIÁ KẾT QUẢ

| D. Because/Because of | 5 | __/5 | |

### Đánh giá:
- **45-50 câu đúng (9-10 điểm):** ⭐⭐⭐⭐⭐ XUẤT SẮC! Sẵn sàng đạt 8+
- **40-44 câu đúng (8-8.9 điểm):** ⭐⭐⭐⭐ GIỎI. Tiếp tục luyện tập
- **35-39 câu đúng (7-7.9 điểm):** ⭐⭐⭐ KHÁ. Cần ôn lại các phần yếu
- **25-34 câu đúng (5-6.9 điểm):** ⭐⭐ TRUNG BÌNH. Học lại từ đầu
- **Dưới 25 câu:** ⭐ YẾU. Cần nỗ lực nhiều hơn
