## 🎯 MỤC TIÊU BÀI HỌC

Sau bài học này, học sinh có thể:
1. ✅ Phân biệt so sánh hơn và so sánh nhất
2. ✅ Áp dụng đúng quy tắc thêm -er/-est hoặc more/most
3. ✅ Nắm vững các tính từ bất quy tắc
4. ✅ Viết lại câu so sánh chính xác

---

## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ SO SÁNH

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  "THAN là HƠN" → So sánh hơn (Comparative)                  │
│  "THE là NHẤT" → So sánh nhất (Superlative)                 │
│                                                             │
│  ① Tính từ NGẮN (1-2 âm tiết): Thêm -er / -est             │
│  ② Tính từ DÀI (3+ âm tiết): Thêm more / most              │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. SO SÁNH HƠN (COMPARATIVE)

**Công thức:**
```
S1 + V + ADJ-er / more + ADJ + THAN + S2
```

**Ví dụ:**
```
✓ Tom is taller than Mary. (Tom cao hơn Mary)
✓ This book is more interesting than that one. (Cuốn sách này thú vị hơn cuốn kia)
```

### 1.3. SO SÁNH NHẤT (SUPERLATIVE)

**Công thức:**
```
S + V + THE + ADJ-est / most + ADJ + (in/of...)
```

**Ví dụ:**
```
✓ Tom is the tallest in his class. (Tom cao nhất lớp)
✓ This is the most interesting book I've ever read. (Đây là cuốn sách thú vị nhất tôi từng đọc)
```

### 1.4. SO SÁNH BẰNG (EQUALITY)

**Công thức:**
```
S1 + V + AS + ADJ + AS + S2
```

**Ví dụ:**
```
✓ Tom is as tall as Peter. (Tom cao bằng Peter)
✓ This book is as interesting as that one. (Cuốn sách này thú vị như cuốn kia)
```

## 📊 PHẦN 2: QUY TẮC THÊM -ER/-EST VÀ MORE/MOST

### 2.1. TÍNH TỪ NGẮN (1 âm tiết hoặc 2 âm tiết kết thúc bằng -y, -le, -ow, -er)

| Tính từ | So sánh hơn | So sánh nhất |
|---------|-------------|--------------|
| tall | tall**er** | the tall**est** |
| old | old**er** | the old**est** |
| young | young**er** | the young**est** |
| fast | fast**er** | the fast**est** |

### 2.2. QUY TẮC CHÍNH TẢ ĐẶC BIỆT

**① Kết thúc bằng -e: Chỉ thêm -r / -st**
| Tính từ | So sánh hơn | So sánh nhất |
|---------|-------------|--------------|
| large | larg**er** | the larg**est** |
| nice | nic**er** | the nic**est** |
| wide | wid**er** | the wid**est** |

**② Kết thúc bằng -y: Đổi y → i rồi thêm -er / -est**
| Tính từ | So sánh hơn | So sánh nhất |
|---------|-------------|--------------|
| happy | happ**ier** | the happ**iest** |
| easy | eas**ier** | the eas**iest** |
| busy | bus**ier** | the bus**iest** |
| early | earl**ier** | the earl**iest** |

**③ Kết thúc: Phụ âm + nguyên âm + phụ âm: Gấp đôi phụ âm cuối**
| Tính từ | So sánh hơn | So sánh nhất |
|---------|-------------|--------------|
| big | bi**gg**er | the bi**gg**est |
| hot | ho**tt**er | the ho**tt**est |
| thin | thi**nn**er | the thi**nn**est |
| fat | fa**tt**er | the fa**tt**est |

### 2.3. TÍNH TỪ DÀI (2+ âm tiết)

| Tính từ | So sánh hơn | So sánh nhất |
|---------|-------------|--------------|
| beautiful | **more** beautiful | **the most** beautiful |
| interesting | **more** interesting | **the most** interesting |
| expensive | **more** expensive | **the most** expensive |
| important | **more** important | **the most** important |

### 2.4. TÍNH TỪ BẤT QUY TẮC (HỌC THUỘC!)

```
┌─────────────────────────────────────────────────────────────┐
│  🔴 PHẢI HỌC THUỘC - ĐỀ THI HAY RA!                        │
├─────────────────────────────────────────────────────────────┤
│  good → better → the best                                   │
│  bad → worse → the worst                                    │
│  far → farther/further → the farthest/furthest             │
│  little → less → the least                                  │
│  many/much → more → the most                                │
│  old → older/elder → the oldest/eldest                      │
└─────────────────────────────────────────────────────────────┘
```

## 🔄 PHẦN 3: CÁC DẠNG VIẾT LẠI CÂU SO SÁNH

### 3.1. SO SÁNH HƠN ↔ SO SÁNH HƠN (ĐẢO NGƯỢC)

**Công thức:**
```
A + more + ADJ + than + B
= B + less + ADJ + than + A
= B + not as/so + ADJ + as + A
```

**Ví dụ:**
```
Tom is taller than Mary.
= Mary is shorter than Tom.
= Mary is not as tall as Tom.
= Mary is less tall than Tom.
```

### 3.2. SO SÁNH NHẤT ↔ SO SÁNH HƠN

**Công thức:**
```
A + the + ADJ-est
= A + ADJ-er + than any other + N (số ít)
= A + ADJ-er + than all the other + N (số nhiều)
= No other + N + is + as + ADJ + as + A
```

**Ví dụ:**
```
Tom is the tallest student in the class.
= Tom is taller than any other student in the class.
= Tom is taller than all the other students in the class.
= No other student in the class is as tall as Tom.
```

### 3.3. SO SÁNH BẰNG ↔ PHỦĐỊNH

**Công thức:**
```
A + as + ADJ + as + B (khẳng định)
= A + not + ADJ-er + than + B
```

**Ví dụ:**
```
Tom is as tall as Peter.
= Tom is not taller than Peter.
= Peter is not taller than Tom.
```

### 3.4. SO SÁNH KÉP (DOUBLE COMPARATIVES)

**Công thức:**
```
The + ADJ-er/more ADJ + S + V, the + ADJ-er/more ADJ + S + V
(Càng... càng...)
```

**Ví dụ:**
```
The older he gets, the wiser he becomes.
(Ông ấy càng già càng khôn ngoan)

The more you study, the better you will be.
(Bạn càng học nhiều, bạn sẽ càng giỏi)
```
