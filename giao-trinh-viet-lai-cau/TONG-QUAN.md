## 🎯 MỤC TIÊU GIÁO TRÌNH

> **Viết lại câu** là dạng bài **CHIẾM 2-3 ĐIỂM** trong đề thi Tiếng Anh lớp 9!
> Học sinh yếu phần này sẽ **MẤT ĐIỂM RẤT NHIỀU**.

### Sau khi hoàn thành giáo trình này, học sinh có thể:

1. ✅ Nhận diện được **15+ cấu trúc viết lại câu** thông dụng
2. ✅ Áp dụng **Thần chú** để chuyển đổi câu nhanh chóng
3. ✅ Làm đúng **≥ 80%** các câu viết lại trong đề thi
4. ✅ Tự tin xử lý các dạng biến đổi câu khó

## 🔥 BẢNG "THẦN CHÚ" VIẾT LẠI CÂU

```
┌─────────────────────────────────────────────────────────────────┐
│ 📌 15 THẦN CHÚ VIẾT LẠI CÂU - HỌC THUỘC LÒNG!                  │
├─────────────────────────────────────────────────────────────────┤
│ 1. BỊ ĐỘNG: "O đảo lên - BE V3 - BY S"                         │
│ 2. SO SÁNH HƠN: "Than là Hơn" → S + V + more/adj-er + than     │
│ 3. SO SÁNH NHẤT: "The là Nhất" → S + V + the most/adj-est      │
│ 4. TOO: "Too = Quá...không thể" → too + adj + to V             │
│ 5. ENOUGH: "Enough = Đủ để" → adj + enough + to V              │
│ 6. BECAUSE → BECAUSE OF: Mệnh đề → Cụm danh từ                 │
│ 7. ALTHOUGH → DESPITE: Mệnh đề → Cụm danh từ/Ving              │
│ 8. IF 0: If + HTĐ, HTĐ (sự thật hiển nhiên)                    │
│ 9. IF 1: If + HTĐ, will + V (có thể xảy ra)                    │
│ 10. IF 2: If + QKĐ, would + V (không có thật ở hiện tại)       │
│ 11. WISH: "Ước là PHẢI LÙI" → Wish + QKĐ (trái ngược HT)       │
│ 12. GIÁN TIẾP: "LÙI thì - ĐỔI ngôi - ĐỔI trạng từ"            │
│ 13. IT TAKES: It takes + O + time + to V                       │
│ 14. SPEND: S + spend + time + V-ing                            │
│ 15. SUGGEST: S + suggest + (that) + S + (should) + V           │
└─────────────────────────────────────────────────────────────────┘
```

## 📖 HƯỚNG DẪN SỬ DỤNG

### Dành cho GIA SƯ:
1. Dạy từng bài theo thứ tự (Cơ bản → Nâng cao → Chuyên sâu)
2. Yêu cầu học sinh **học thuộc THẦN CHÚ** trước
3. Làm bài tập theo thứ tự: Nhận diện → Chuyển đổi → Tổng hợp
4. Kiểm tra bằng **Bài Test cuối mỗi phần**

### Dành cho HỌC SINH:
1. Đọc lý thuyết và **học thuộc Thần chú**
2. Làm bài tập từ dễ đến khó
3. **Chép lại** các câu sai nhiều lần
4. Ôn lại bằng cách **tự ra đề** cho bản thân

## ⚠️ LƯU Ý QUAN TRỌNG

### 🔴 Các lỗi học sinh HAY MẮC:

1. **Không nhớ V3 (quá khứ phân từ)** → Viết sai câu bị động
2. **Nhầm lẫn Because vs Because of** → Dùng mệnh đề vs cụm từ
3. **Quên lùi thì trong câu gián tiếp** → Said → had said
4. **Nhầm would vs will trong If 2** → Dùng would cho giả định
5. **Không đổi too → enough đúng cách** → Quên đổi tính từ trái nghĩa

### ✅ Cách khắc phục:

1. **Học thuộc 30 động từ bất quy tắc** phổ biến
2. **Làm nhiều bài tập** để quen tay
3. **Chép lại câu sai** 10-20 lần
4. **Tự kiểm tra** hàng ngày bằng flashcard
