## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ SUGGEST

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ SUGGEST:                                       │
│                                                             │
│  "SUGGEST + V-ING" (phổ biến nhất)                          │
│  "SUGGEST + (THAT) + S + (SHOULD) + V" (dạng that-clause)  │
│  "SUGGEST + N" (gợi ý cái gì)                               │
│                                                             │
│  📌 SUGGEST KHÔNG đi với TO V!                              │
│     ❌ SAIIIIII: suggest to go                              │
│     ✓ ĐÚNG: suggest going / suggest that we should go      │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. CÁC CẤU TRÚC CỦA SUGGEST

**Cấu trúc 1: SUGGEST + V-ING**
```
S + SUGGEST(S/ED) + V-ING
```

**Ví dụ:**
```
✓ I suggest going to the beach.
  (Tôi gợi ý đi biển)

✓ She suggested having a party.
  (Cô ấy gợi ý tổ chức tiệc)

✓ He suggested eating out tonight.
  (Anh ấy gợi ý đi ăn ngoài tối nay)
```

**Cấu trúc 2: SUGGEST + (THAT) + S + (SHOULD) + V**
```
S + SUGGEST(S/ED) + (THAT) + S + (SHOULD) + V (nguyên thể)
```

**Ví dụ:**
```
✓ I suggest (that) we (should) go to the beach.
  (Tôi gợi ý chúng ta nên đi biển)

✓ She suggested (that) he (should) see a doctor.
  (Cô ấy gợi ý anh ấy nên đi khám bác sĩ)

✓ The teacher suggested (that) we (should) study harder.
  (Thầy giáo gợi ý chúng tôi nên học chăm hơn)
```

**Cấu trúc 3: SUGGEST + N**
```
S + SUGGEST(S/ED) + N / N phrase
```

**Ví dụ:**
```
✓ Can you suggest a good restaurant?
  (Bạn có thể gợi ý một nhà hàng tốt không?)

✓ She suggested a new approach.
  (Cô ấy gợi ý một cách tiếp cận mới)
```

### 1.3. CẤU TRÚC RECOMMEND

**Công thức:** (giống SUGGEST)
```
S + RECOMMEND + V-ING
S + RECOMMEND + (THAT) + S + (SHOULD) + V
S + RECOMMEND + N
S + RECOMMEND + O + TO V (khác với SUGGEST!)
```

**Ví dụ:**
```
✓ I recommend visiting Ha Long Bay.
  (Tôi khuyên nên thăm Vịnh Hạ Long)

✓ The doctor recommended (that) he (should) rest.
  (Bác sĩ khuyên anh ấy nên nghỉ ngơi)

✓ I recommend you to see this movie.
  (Tôi khuyên bạn xem bộ phim này)
```

### 1.4. CÁC CÁCH NÓI GỢI Ý KHÁC

| Cấu trúc | Ví dụ |
|----------|-------|
| **Why don't we...?** | Why don't we go to the cinema? |
| **How about + V-ing?** | How about going to the beach? |
| **What about + V-ing?** | What about having lunch together? |
| **Let's + V** | Let's go shopping. |
| **Shall we + V?** | Shall we dance? |
| **Why not + V?** | Why not try again? |

## 🔄 PHẦN 2: CHUYỂN ĐỔI CÂU

### 2.1. CHUYỂN ĐỔI CÁC DẠNG GỢI Ý

```
"Let's go to the beach," she said.
= She suggested going to the beach.
= She suggested that we should go to the beach.
= She suggested that we go to the beach.

"Why don't we have a picnic?" he said.
= He suggested having a picnic.
= He suggested that we should have a picnic.

"How about eating out tonight?" she said.
= She suggested eating out tonight.
```

### 2.2. TỪ CÂU KHUYÊN → SUGGEST

```
"You should see a doctor," she said to him.
= She suggested (that) he (should) see a doctor.
= She advised him to see a doctor.
```

### 2.3. BẢNG CHUYỂN ĐỔI

| Câu gốc | SUGGEST |
|---------|---------|
| "Let's + V..." | S + suggested + V-ing |
| "Why don't we + V...?" | S + suggested + V-ing |
| "How about + V-ing...?" | S + suggested + V-ing |
| "What about + V-ing...?" | S + suggested + V-ing |
| "Shall we + V...?" | S + suggested + V-ing |
| "Why not + V...?" | S + suggested + V-ing |
