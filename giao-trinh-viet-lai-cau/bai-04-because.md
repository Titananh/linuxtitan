## 🎯 MỤC TIÊU BÀI HỌC

Sau bài học này, học sinh có thể:
1. ✅ Phân biệt BECAUSE và BECAUSE OF
2. ✅ Chuyển đổi câu giữa hai cấu trúc
3. ✅ Áp dụng với các từ đồng nghĩa (Since, As, Due to, Owing to)

## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ BECAUSE/BECAUSE OF

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  "BECAUSE + MỆNH ĐỀ" (có S + V)                             │
│  "BECAUSE OF + CỤM DANH TỪ/VING" (không có S + V)          │
│                                                             │
│  📌 BECAUSE = Bởi vì (theo sau là câu đầy đủ)               │
│  📌 BECAUSE OF = Bởi vì (theo sau là cụm từ)               │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. CẤU TRÚC BECAUSE

**Công thức:**
```
S + V + BECAUSE + S + V
(Mệnh đề chính) + BECAUSE + (Mệnh đề phụ)
```

**Ví dụ:**
```
✓ He was late because he missed the bus.
  (Anh ấy trễ vì anh ấy lỡ xe buýt)

✓ She stayed home because she was sick.
  (Cô ấy ở nhà vì cô ấy bị ốm)

✓ I can't sleep because the music is too loud.
  (Tôi không thể ngủ vì nhạc quá ồn)
```

### 1.3. CẤU TRÚC BECAUSE OF

**Công thức:**
```
S + V + BECAUSE OF + N/N phrase/V-ing
```

**Ví dụ:**
```
✓ He was late because of the traffic.
  (Anh ấy trễ vì giao thông)

✓ She stayed home because of her illness.
  (Cô ấy ở nhà vì bệnh của cô ấy)

✓ I can't sleep because of the loud music.
  (Tôi không thể ngủ vì nhạc ồn)
```

## 🔄 PHẦN 2: CHUYỂN ĐỔI CÂU

### 2.1. BECAUSE → BECAUSE OF

```
┌─────────────────────────────────────────────────────────────┐
│  📌 QUY TẮC CHUYỂN ĐỔI:                                     │
│                                                             │
│  BECAUSE + S + V → BECAUSE OF + N/Ving                      │
│                                                             │
│  CÁCH CHUYỂN:                                               │
│  ① Nếu có tính từ: ADJ → N (thêm -ness, -ty, the + adj)    │
│  ② Nếu có động từ: V → Ving / N                             │
│  ③ Nếu chủ ngữ = sở hữu: S → his/her/their + N              │
└─────────────────────────────────────────────────────────────┘
```

**Bảng chuyển đổi tính từ → danh từ:**
| Tính từ (ADJ) | Danh từ (N) |
|---------------|-------------|
| sick / ill | **illness / sickness** |
| lazy | **laziness** |
| careless | **carelessness** |
| absent | **absence** |
| poor | **poverty** |
| rich | **wealth** |
| hot | **heat / hot weather** |
| cold | **cold weather** |
| noisy | **noise** |
| tired | **tiredness** |
| busy | **busyness** |
| happy | **happiness** |
| kind | **kindness** |
| stupid | **stupidity** |

**Ví dụ chuyển đổi:**
```
Because + S + BE + ADJ → Because of + (the/his/her) + N

✓ Because she was sick
  → Because of her sickness / her illness

✓ Because he was lazy
  → Because of his laziness

✓ Because the weather was cold
  → Because of the cold weather
```

```
Because + S + V → Because of + (the/his/her) + N/Ving

✓ Because it rained heavily
  → Because of the heavy rain

✓ Because he helped me
  → Because of his help

✓ Because they arrived late
  → Because of their late arrival
```

### 2.2. VÍ DỤ CHI TIẾT

**Ví dụ 1:**
```
BECAUSE: He failed the exam because he was lazy.
BECAUSE OF: He failed the exam because of his laziness.
```

**Ví dụ 2:**
```
BECAUSE: The match was cancelled because it rained heavily.
BECAUSE OF: The match was cancelled because of the heavy rain.
```

**Ví dụ 3:**
```
BECAUSE: She couldn't sleep because the music was loud.
BECAUSE OF: She couldn't sleep because of the loud music.
```

**Ví dụ 4:**
```
BECAUSE: We stayed home because the weather was bad.
BECAUSE OF: We stayed home because of the bad weather.
```

## 📊 PHẦN 3: CÁC TỪ ĐỒNG NGHĨA

### 3.1. BECAUSE = SINCE = AS (+ mệnh đề)

```
✓ Because he was tired, he went to bed early.
= Since he was tired, he went to bed early.
= As he was tired, he went to bed early.
```

### 3.2. BECAUSE OF = DUE TO = OWING TO = ON ACCOUNT OF (+ cụm danh từ)

```
✓ He failed because of his laziness.
= He failed due to his laziness.
= He failed owing to his laziness.
= He failed on account of his laziness.
```

### 3.3. BẢNG TÓM TẮT

| Theo sau bởi MỆNH ĐỀ (S + V) | Theo sau bởi CỤM TỪ (N/Ving) |
|------------------------------|------------------------------|
| BECAUSE | BECAUSE OF |
| SINCE | DUE TO |
| AS | OWING TO |
| | ON ACCOUNT OF |

## 📌 GHI NHỚ CUỐI BÀI

```
┌─────────────────────────────────────────────────────────────┐
│  📌 BECAUSE + MỆNH ĐỀ (S + V)                               │
│     = SINCE + S + V                                         │
│     = AS + S + V                                            │
│                                                             │
│  📌 BECAUSE OF + CỤM DANH TỪ / VING                        │
│     = DUE TO + N                                            │
│     = OWING TO + N                                          │
│     = ON ACCOUNT OF + N                                     │
│                                                             │
│  📌 CHUYỂN ĐỔI: ADJ → N (thêm -ness, -ty, -ce...)          │
│     sick → sickness / illness                               │
│     lazy → laziness                                         │
│     absent → absence                                        │
│     careless → carelessness                                 │
└─────────────────────────────────────────────────────────────┘
```
