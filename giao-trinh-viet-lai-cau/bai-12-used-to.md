## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ USED TO

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  "USED TO + V" → ĐÃ TỪNG (thói quen quá khứ, giờ không còn)│
│  "BE USED TO + V-ING/N" → QUEN VỚI (đã quen rồi)           │
│  "GET USED TO + V-ING/N" → LÀM QUEN VỚI (đang làm quen)    │
│                                                             │
│  📌 USED TO: theo sau là V nguyên thể                       │
│  📌 BE/GET USED TO: theo sau là V-ING hoặc DANH TỪ         │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. CẤU TRÚC USED TO + V

**Công thức:**
```
(+) S + USED TO + V (nguyên thể)
(-) S + DIDN'T USE TO + V (nguyên thể)
(?) DID + S + USE TO + V (nguyên thể)?
```

**Cách dùng:** Diễn tả **thói quen/trạng thái trong quá khứ**, giờ **không còn nữa**

**Ví dụ:**
```
✓ I used to play football when I was young.
  (Tôi đã từng chơi bóng đá khi còn trẻ) - Giờ không chơi nữa

✓ She used to live in Hanoi.
  (Cô ấy đã từng sống ở Hà Nội) - Giờ không sống ở đó nữa

✓ He didn't use to smoke.
  (Anh ấy đã từng không hút thuốc) - Giờ có thể hút

✓ Did you use to have long hair?
  (Bạn đã từng có tóc dài không?)
```

### 1.3. CẤU TRÚC BE USED TO + V-ING/N

**Công thức:**
```
S + BE (am/is/are/was/were) + USED TO + V-ING / N
```

**Cách dùng:** Diễn tả **đã quen với** việc gì đó (trạng thái đã quen)

**Ví dụ:**
```
✓ I am used to getting up early.
  (Tôi quen dậy sớm rồi) - Đã quen

✓ She is used to living alone.
  (Cô ấy quen sống một mình rồi)

✓ He is used to the cold weather.
  (Anh ấy quen với thời tiết lạnh rồi)

✓ They are used to working hard.
  (Họ quen làm việc vất vả rồi)
```

### 1.4. CẤU TRÚC GET USED TO + V-ING/N

**Công thức:**
```
S + GET/GOT/WILL GET + USED TO + V-ING / N
```

**Cách dùng:** Diễn tả **quá trình làm quen** với việc gì đó (đang dần quen)

**Ví dụ:**
```
✓ I am getting used to my new job.
  (Tôi đang quen dần với công việc mới)

✓ She got used to living in the city.
  (Cô ấy đã dần quen với cuộc sống thành phố)

✓ You will get used to it soon.
  (Bạn sẽ sớm quen với nó thôi)
```

## 📊 PHẦN 2: SO SÁNH BA CẤU TRÚC

| Cấu trúc | Công thức | Nghĩa | Ví dụ |
|----------|-----------|-------|-------|
| **USED TO + V** | S + used to + V | Đã từng (quá khứ) | I used to play tennis. |
| **BE USED TO + V-ing** | S + be + used to + V-ing | Quen với (đã quen) | I am used to playing tennis. |
| **GET USED TO + V-ing** | S + get + used to + V-ing | Làm quen với (đang quen) | I am getting used to playing tennis. |

```
┌─────────────────────────────────────────────────────────────┐
│  📌 SỰ KHÁC BIỆT QUAN TRỌNG:                                │
│                                                             │
│  USED TO + V (nguyên thể): Thói quen QUÁ KHỨ               │
│  BE USED TO + V-ING: Trạng thái ĐÃ QUEN                     │
│  GET USED TO + V-ING: Quá trình ĐANG LÀM QUEN               │
└─────────────────────────────────────────────────────────────┘
```

## 🔄 PHẦN 3: VIẾT LẠI CÂU

### 3.1. CHUYỂN ĐỔI VỚI "NO LONGER" / "NOT...ANYMORE"

```
S + USED TO + V
= S + NO LONGER + V / S + NOT + V + ANYMORE
```

**Ví dụ:**
```
I used to play football.
= I no longer play football.
= I don't play football anymore.

She used to live in Hanoi.
= She no longer lives in Hanoi.
= She doesn't live in Hanoi anymore.
```

### 3.2. CHUYỂN ĐỔI VỚI "IN THE PAST" / "WHEN I WAS YOUNG"

```
In the past, S + V-ed
= S + USED TO + V
```

**Ví dụ:**
```
In the past, I walked to school every day.
= I used to walk to school every day.

When I was young, I played video games a lot.
= I used to play video games a lot when I was young.
```
