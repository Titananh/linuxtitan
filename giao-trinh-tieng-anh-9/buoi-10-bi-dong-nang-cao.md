## 📚 PHẦN 2: BỊ ĐỘNG ĐẶC BIỆT (30 PHÚT)

### 2.1. CÂU CÓ 2 TÂN NGỮ

**Một số động từ có thể có 2 tân ngữ:**
- give, send, show, tell, teach, buy, make, offer, pay, promise...

**Cấu trúc:**
```
Active:  S + V + O1 (người) + O2 (vật)
Passive: 
   Cách 1: O1 + BE + V3 + O2 (phổ biến hơn)
   Cách 2: O2 + BE + V3 + TO + O1
```

**Ví dụ:**
```
Active:  My mother gave me a gift.
                     O1   O2
Passive 1: I was given a gift (by my mother).
Passive 2: A gift was given to me (by my mother).
```

```
Active:  The teacher teaches us English.
                       O1    O2
Passive 1: We are taught English (by the teacher).
Passive 2: English is taught to us (by the teacher).
```

### 2.2. CÂU MỆNH LỆNH

```
Active:  V + O!
Passive: Let + O + BE + V3
         hoặc: O + SHOULD BE + V3
```

**Ví dụ:**
```
Active:  Clean this room!
Passive: Let this room be cleaned!
         This room should be cleaned!

Active:  Don't touch this button!
Passive: Let this button not be touched!
         This button shouldn't be touched!
```

### 2.3. CÂU VỚI ĐỘNG TỪ TƯỜNG THUẬT (DẠNG ĐẶC BIỆT)

**Các động từ:** say, think, believe, know, expect, report, consider...

**2 cách chuyển:**

**Cách 1: IT + BE + V3 + THAT + clause**
```
Active:  People say that he is a good doctor.
Passive: It is said that he is a good doctor.
```

**Cách 2: S + BE + V3 + TO V**
```
Active:  People say that he is a good doctor.
Passive: He is said to be a good doctor.
```

**Ví dụ thêm:**
```
Active:  People believe that she is the best singer.
Passive 1: It is believed that she is the best singer.
Passive 2: She is believed to be the best singer.

Active:  They think that the exam is difficult.
Passive 1: It is thought that the exam is difficult.
Passive 2: The exam is thought to be difficult.
```

### 2.4. CÂU VỚI ĐỘNG TỪ KHIẾN (MAKE, HAVE, LET)

**① MAKE:**
```
Active:  S + make + O + V (bare infinitive)
Passive: O + BE + made + TO V
```
```
Active:  The teacher made us do homework.
Passive: We were made to do homework (by the teacher).
```

**② HAVE:**
```
Active:  S + have + O (người) + V
Passive: S + have + O (vật) + V3
```
```
Active:  I had him repair my car.
Passive: I had my car repaired (by him).
```

**③ LET:**
```
Active:  S + let + O + V
Passive: O + BE + allowed/permitted + TO V
```
```
Active:  My parents let me go to the party.
Passive: I was allowed to go to the party (by my parents).
```

## 📚 PHẦN 3: CẤU TRÚC SUGGEST (25 PHÚT)

### 3.1. CÁC CÁCH DÙNG SUGGEST

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ SUGGEST:                                       │
│  "SUGGEST + V-ING / THAT + S + (SHOULD) + V"               │
└─────────────────────────────────────────────────────────────┘
```

### 3.2. CẤU TRÚC CHI TIẾT

**① SUGGEST + V-ING** (Phổ biến nhất)
```
S + suggest + V-ING + ...
```
**Ví dụ:**
- I **suggest going** to the beach.
- She **suggested visiting** the museum.

**② SUGGEST + THAT + S + (SHOULD) + V** (nguyên thể)
```
S + suggest + that + S + (should) + V + ...
```
**Ví dụ:**
- I **suggest that we (should) go** to the beach.
- He **suggested that she (should) study** harder.

**③ SUGGEST + NOUN/PRONOUN**
```
S + suggest + noun/noun phrase
```
**Ví dụ:**
- Can you **suggest a good restaurant**?
- He **suggested a solution** to the problem.

### 3.3. LƯU Ý QUAN TRỌNG

```
⚠️ KHÔNG DÙNG: Suggest + to V
❌ I suggest to go to the beach.
✅ I suggest going to the beach.
✅ I suggest that we go to the beach.

⚠️ KHÔNG DÙNG: Suggest + somebody + to V
❌ I suggest you to go home.
✅ I suggest that you go home.
✅ I suggest you should go home.
```

### 3.4. CÁC CẤU TRÚC TƯƠNG ĐƯƠNG

| Cấu trúc | Nghĩa | Ví dụ |
|----------|-------|-------|
| suggest + V-ing | gợi ý | I suggest visiting Ha Long Bay. |
| How about + V-ing? | Thế còn...? | How about visiting Ha Long Bay? |
| What about + V-ing? | Thế còn...? | What about visiting Ha Long Bay? |
| Why don't we + V? | Sao chúng ta không...? | Why don't we visit Ha Long Bay? |
| Let's + V | Hãy... | Let's visit Ha Long Bay. |
| Shall we + V? | Chúng ta... nhé? | Shall we visit Ha Long Bay? |

### 3.5. BÀI TẬP VIẾT LẠI CÂU NHANH

```
1. "Let's go to the cinema," he said.
   → He suggested ___________________________________

2. "Why don't we have a picnic?" she said.
   → She suggested ___________________________________

3. "How about ordering pizza?" Tom said.
   → Tom suggested ___________________________________
```

**Đáp án:**
```
1. He suggested going to the cinema.
2. She suggested having a picnic.
3. Tom suggested ordering pizza.
```
