## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ TOO/ENOUGH

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  "TOO = QUÁ... KHÔNG THỂ" (nghĩa tiêu cực)                  │
│  "ENOUGH = ĐỦ ĐỂ" (nghĩa tích cực/trung tính)               │
│                                                             │
│  📌 TOO đứng TRƯỚC tính từ/trạng từ                         │
│  📌 ENOUGH đứng SAU tính từ/trạng từ, TRƯỚC danh từ         │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. CẤU TRÚC TOO

**Công thức:**
```
S + V + TOO + ADJ/ADV + (FOR O) + TO V
```

**Nghĩa:** Quá... đến nỗi không thể...

**Ví dụ:**
```
✓ The box is too heavy to carry.
  (Cái hộp quá nặng để mang)
  
✓ He runs too slowly to win the race.
  (Anh ấy chạy quá chậm để thắng cuộc đua)
  
✓ This coffee is too hot for me to drink.
  (Cà phê này quá nóng để tôi uống)
```

### 1.3. CẤU TRÚC ENOUGH

**Công thức với tính từ/trạng từ:**
```
S + V + ADJ/ADV + ENOUGH + (FOR O) + TO V
```

**Công thức với danh từ:**
```
S + V + ENOUGH + N + (FOR O) + TO V
```

**Nghĩa:** Đủ... để...

**Ví dụ:**
```
✓ She is old enough to drive a car.
  (Cô ấy đủ tuổi để lái xe)
  
✓ He runs fast enough to win the race.
  (Anh ấy chạy đủ nhanh để thắng cuộc đua)
  
✓ I have enough money to buy this book.
  (Tôi có đủ tiền để mua cuốn sách này)
```

## 🔄 PHẦN 2: CHUYỂN ĐỔI CÂU

### 2.1. TOO ↔ ENOUGH

```
┌─────────────────────────────────────────────────────────────┐
│  📌 QUY TẮC CHUYỂN ĐỔI:                                     │
│                                                             │
│  TOO + ADJ + TO V = NOT + ADJ (đối nghĩa) + ENOUGH + TO V  │
│                                                             │
│  ⚠️ LƯU Ý: Phải ĐỔI TÍNH TỪ SANG NGHĨA ĐỐI LẬP!           │
└─────────────────────────────────────────────────────────────┘
```

**Bảng tính từ đối nghĩa:**
| Tính từ | Đối nghĩa |
|---------|-----------|
| old | young |
| tall | short |
| big | small |
| heavy | light |
| hot | cold |
| fast | slow |
| easy | difficult |
| strong | weak |
| rich | poor |
| good | bad |

**Ví dụ:**
```
The box is too heavy to carry.
= The box is not light enough to carry.

He is too young to drive.
= He is not old enough to drive.

This coffee is too hot to drink.
= This coffee is not cold enough to drink.
```

### 2.2. TOO/ENOUGH ↔ SO...THAT

**Công thức:**
```
TOO + ADJ + TO V = SO + ADJ + THAT + S + CAN'T/COULDN'T + V

ADJ + ENOUGH + TO V = SO + ADJ + THAT + S + CAN/COULD + V
```

**Ví dụ:**
```
The box is too heavy to carry.
= The box is so heavy that I can't carry it.

She is old enough to drive.
= She is so old that she can drive.
```

### 2.3. TOO/ENOUGH ↔ SUCH...THAT

**Công thức:**
```
TOO + ADJ + A/AN + N + TO V = SUCH + A/AN + ADJ + N + THAT + S + CAN'T + V
```

**Ví dụ:**
```
It is too difficult a question to answer.
= It is such a difficult question that I can't answer it.
```

## 📊 PHẦN 3: BẢNG TÓM TẮT

| Cấu trúc | Công thức | Ví dụ |
|----------|-----------|-------|
| **TOO** | S + V + too + adj + to V | He is too young to drive. |
| **ENOUGH (adj)** | S + V + adj + enough + to V | She is old enough to vote. |
| **ENOUGH (n)** | S + V + enough + n + to V | I have enough time to finish. |
| **SO...THAT (không thể)** | S + V + so + adj + that + S + can't + V | He is so young that he can't drive. |
| **SO...THAT (có thể)** | S + V + so + adj + that + S + can + V | She is so old that she can vote. |

- A. enough fast

**6.** This bag is __________ for me to carry.

- C. enough heavy

- A. old enough

- D. quickly too

## 📌 GHI NHỚ CUỐI BÀI

```
┌─────────────────────────────────────────────────────────────┐
│  📌 TOO = Quá... không thể (nghĩa tiêu cực)                 │
│     → TOO + ADJ + TO V                                      │
│                                                             │
│  📌 ENOUGH = Đủ để (nghĩa tích cực)                         │
│     → ADJ + ENOUGH + TO V                                   │
│     → ENOUGH + N + TO V                                     │
│                                                             │
│  📌 Chuyển đổi: Phải ĐỔI TÍNH TỪ ĐỐI NGHĨA!                │
│     too young = not old enough                              │
│     too heavy = not light enough                            │
│                                                             │
│  📌 SO...THAT:                                              │
│     too + adj = so + adj + that + can't                     │
│     adj + enough = so + adj + that + can                    │
└─────────────────────────────────────────────────────────────┘
```
