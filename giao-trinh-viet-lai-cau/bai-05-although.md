## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ ALTHOUGH/DESPITE

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  "ALTHOUGH + MỆNH ĐỀ" (có S + V)                            │
│  "DESPITE/IN SPITE OF + CỤM TỪ" (không có S + V)           │
│                                                             │
│  📌 Nghĩa: MẶC DÙ... NHƯNG...                               │
│  📌 Thể hiện SỰ TƯƠNG PHẢN                                   │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. CẤU TRÚC ALTHOUGH / THOUGH / EVEN THOUGH

**Công thức:**
```
ALTHOUGH/THOUGH/EVEN THOUGH + S + V, S + V
S + V + ALTHOUGH/THOUGH/EVEN THOUGH + S + V
```

**Ví dụ:**
```
✓ Although it rained heavily, we still went out.
  (Mặc dù trời mưa to, chúng tôi vẫn ra ngoài)

✓ She passed the exam although she didn't study hard.
  (Cô ấy đậu kỳ thi mặc dù không học chăm)

✓ Even though he is rich, he is not happy.
  (Mặc dù anh ấy giàu, anh ấy không hạnh phúc)
```

### 1.3. CẤU TRÚC DESPITE / IN SPITE OF

**Công thức:**
```
DESPITE/IN SPITE OF + N/N phrase/V-ing, S + V
S + V + DESPITE/IN SPITE OF + N/N phrase/V-ing
```

**Ví dụ:**
```
✓ Despite the rain, we still went out.
  (Mặc dù mưa, chúng tôi vẫn ra ngoài)

✓ She passed the exam in spite of not studying hard.
  (Cô ấy đậu kỳ thi mặc dù không học chăm)

✓ In spite of his wealth, he is not happy.
  (Mặc dù giàu có, anh ấy không hạnh phúc)
```

### 1.4. CẤU TRÚC DESPITE THE FACT THAT / IN SPITE OF THE FACT THAT

**Công thức:**
```
DESPITE THE FACT THAT + S + V
IN SPITE OF THE FACT THAT + S + V
```

**Ví dụ:**
```
✓ Despite the fact that it rained, we went out.
✓ In spite of the fact that he is rich, he is unhappy.
```

## 🔄 PHẦN 2: CHUYỂN ĐỔI CÂU

### 2.1. ALTHOUGH → DESPITE/IN SPITE OF

```
┌─────────────────────────────────────────────────────────────┐
│  📌 QUY TẮC CHUYỂN ĐỔI:                                     │
│                                                             │
│  ALTHOUGH + S + V → DESPITE/IN SPITE OF + N/Ving            │
│                                                             │
│  CÁCH CHUYỂN (giống BECAUSE → BECAUSE OF):                  │
│  ① Nếu có tính từ: ADJ → N (thêm -ness, -ty, the + adj)    │
│  ② Nếu có động từ: V → Ving / N                             │
│  ③ Nếu chủ ngữ = sở hữu: S → his/her/their + N              │
└─────────────────────────────────────────────────────────────┘
```

**Ví dụ chuyển đổi:**
```
Although + S + BE + ADJ → Despite + (the/his/her) + N

✓ Although she was sick → Despite her sickness
✓ Although he was poor → Despite his poverty
✓ Although the weather was bad → Despite the bad weather
```

```
Although + S + V → Despite + N/Ving

✓ Although it rained → Despite the rain / Despite raining
✓ Although he helped me → Despite his help
✓ Although they tried hard → Despite their hard efforts / trying hard
```

### 2.2. VÍ DỤ CHI TIẾT

**Ví dụ 1:**
```
ALTHOUGH: Although he was tired, he kept working.
DESPITE: Despite his tiredness, he kept working.
DESPITE + Ving: Despite being tired, he kept working.
```

**Ví dụ 2:**
```
ALTHOUGH: Although it rained heavily, we went out.
IN SPITE OF: In spite of the heavy rain, we went out.
IN SPITE OF + Ving: In spite of raining heavily, we went out.
```

**Ví dụ 3:**
```
ALTHOUGH: Although she is rich, she is not happy.
DESPITE: Despite her wealth/richness, she is not happy.
DESPITE + Ving: Despite being rich, she is not happy.
```

### 2.3. ALTHOUGH ↔ BUT/HOWEVER

**Công thức:**
```
ALTHOUGH + clause 1, clause 2
= Clause 1. HOWEVER, clause 2.
= Clause 1, BUT clause 2.
```

**Ví dụ:**
```
Although he was tired, he kept working.
= He was tired. However, he kept working.
= He was tired, but he kept working.
```

## 📊 PHẦN 3: SO SÁNH ALTHOUGH VÀ BECAUSE

| | ALTHOUGH (Mặc dù) | BECAUSE (Bởi vì) |
|---|-------------------|------------------|
| **Nghĩa** | Tương phản | Nguyên nhân |
| **Cấu trúc** | Although + S + V | Because + S + V |
| **Dạng cụm từ** | Despite/In spite of + N | Because of + N |
| **Ví dụ** | Although it rained, we went out. | Because it rained, we stayed home. |

**So sánh:**
```
ALTHOUGH it rained, we STILL went out. (Tương phản)
BECAUSE it rained, we STAYED home. (Nguyên nhân)

DESPITE the rain, we went out.
BECAUSE OF the rain, we stayed home.
```
