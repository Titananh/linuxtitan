## 🎯 MỤC TIÊU BÀI HỌC

Sau bài học này, học sinh có thể:
1. ✅ Hiểu cách rút gọn mệnh đề quan hệ
2. ✅ Sử dụng V-ING, V3/V-ED, TO V đúng cách
3. ✅ Viết lại câu rút gọn mệnh đề quan hệ
4. ✅ Làm đúng ≥ 80% bài tập

## 📚 PHẦN 1: LÝ THUYẾT

### 1.1. THẦN CHÚ RÚT GỌN MỆNH ĐỀ QUAN HỆ

```
┌─────────────────────────────────────────────────────────────┐
│  ⭐ THẦN CHÚ:                                               │
│                                                             │
│  "CHỦ ĐỘNG → V-ING" (bỏ who/which/that + BE hoặc chuyển V) │
│  "BỊ ĐỘNG → V3/V-ED" (bỏ who/which/that + BE)              │
│  "THỨ TỰ/DUY NHẤT → TO V" (the first, the only, the last)  │
│                                                             │
│  📌 Điều kiện: Đại từ quan hệ phải làm CHỦ NGỮ             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2. RÚT GỌN VỚI V-ING (PRESENT PARTICIPLE)

**Điều kiện:** Mệnh đề quan hệ ở dạng **CHỦ ĐỘNG**

**Quy tắc:**
```
① Bỏ đại từ quan hệ (who/which/that)
② Nếu có BE + V-ing: Bỏ BE, giữ V-ing
③ Nếu là động từ thường: Chuyển V → V-ing
```

**Ví dụ:**
```
Đầy đủ: The man who is standing over there is my father.
Rút gọn: The man STANDING over there is my father.
         (Bỏ who is)

Đầy đủ: The girl who works in the bank is my sister.
Rút gọn: The girl WORKING in the bank is my sister.
         (Bỏ who, đổi works → working)

Đầy đủ: The children who are playing in the park are happy.
Rút gọn: The children PLAYING in the park are happy.
```

### 1.3. RÚT GỌN VỚI V3/V-ED (PAST PARTICIPLE)

**Điều kiện:** Mệnh đề quan hệ ở dạng **BỊ ĐỘNG**

**Quy tắc:**
```
① Bỏ đại từ quan hệ (who/which/that)
② Bỏ BE (is/are/was/were)
③ Giữ lại V3/V-ed
```

**Ví dụ:**
```
Đầy đủ: The book which was written by Mark Twain is famous.
Rút gọn: The book WRITTEN by Mark Twain is famous.
         (Bỏ which was)

Đầy đủ: The car which was made in Japan is expensive.
Rút gọn: The car MADE in Japan is expensive.

Đầy đủ: The man who was injured in the accident is in hospital.
Rút gọn: The man INJURED in the accident is in hospital.
```

### 1.4. RÚT GỌN VỚI TO V (INFINITIVE)

**Điều kiện:** Trước danh từ có:
- **The first / The second / The last**
- **The only**
- **So sánh nhất (the best, the most...)**

**Quy tắc:**
```
① Bỏ đại từ quan hệ
② Chuyển động từ → TO + V (nguyên thể)
```

**Ví dụ:**
```
Đầy đủ: He was the first man who reached the top of the mountain.
Rút gọn: He was the first man TO REACH the top of the mountain.

Đầy đủ: She is the only student who passed the exam.
Rút gọn: She is the only student TO PASS the exam.

Đầy đủ: This is the best hotel that we can find.
Rút gọn: This is the best hotel TO FIND.
```

## 📊 PHẦN 2: BẢNG TÓM TẮT

| Dạng mệnh đề | Cách rút gọn | Ví dụ |
|--------------|--------------|-------|
| **Chủ động** | V-ING | The man who works here → The man working here |
| **Bị động** | V3/V-ED | The book which was written → The book written |
| **Thứ tự/Duy nhất** | TO V | The first man who came → The first man to come |

## 🔄 PHẦN 3: CÁC BƯỚC RÚT GỌN

### 3.1. SƠ ĐỒ QUYẾT ĐỊNH

```
┌─────────────────────────────────────────────────────────────┐
│  📌 BƯỚC 1: Kiểm tra đại từ quan hệ có làm CHỦ NGỮ không?  │
│             → Không → Không thể rút gọn                     │
│             → Có → Tiếp tục                                 │
│                                                             │
│  📌 BƯỚC 2: Mệnh đề CHỦ ĐỘNG hay BỊ ĐỘNG?                  │
│             → Chủ động → Dùng V-ING                         │
│             → Bị động → Dùng V3/V-ED                        │
│                                                             │
│  📌 BƯỚC 3: Có THE FIRST/LAST/ONLY/SO SÁNH NHẤT không?     │
│             → Có → Dùng TO V                                │
└─────────────────────────────────────────────────────────────┘
```

### 3.2. VÍ DỤ CHI TIẾT

**Ví dụ 1: Chủ động**
```
Câu đầy đủ: The woman who lives next door is a doctor.
            → who = chủ ngữ ✓
            → lives = chủ động ✓
Câu rút gọn: The woman LIVING next door is a doctor.
```

**Ví dụ 2: Bị động**
```
Câu đầy đủ: The movie which was directed by Steven Spielberg won an Oscar.
            → which = chủ ngữ ✓
            → was directed = bị động ✓
Câu rút gọn: The movie DIRECTED by Steven Spielberg won an Oscar.
```

**Ví dụ 3: To V**
```
Câu đầy đủ: Neil Armstrong was the first man who walked on the moon.
            → the first ✓
Câu rút gọn: Neil Armstrong was the first man TO WALK on the moon.
```
